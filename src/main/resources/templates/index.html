Recherche avancée
Aide & Support

Pour ajouter une personne, cliquez sur le bouton Ajouter une personne dans la section Actions Rapides, puis sélectionnez le type de personne que vous souhaitez ajouter.

Pour rechercher une personne, cliquez sur le bouton Recherche avancée dans la section Actions Rapides, puis remplissez les critères de recherche.

Pour modifier ou supprimer une personne, accédez d'abord à la liste correspondante (Enseignants, Étudiants ou Personnel), puis utilisez les boutons d'action disponibles pour chaque entrée.
